# Fonter

`JetBrainsMonoNerdFont-Regular.ttf` og `JetBrainsMonoNerdFont-Bold.ttf` er
JetBrains Mono Nerd Font (patchet med Nerd Fonts-ikonene). Samme font som
Omarchy bruker som standard, og som ikonene i appen er hentet fra.

- Kilde: https://github.com/ryanoasis/nerd-fonts/releases (JetBrainsMono)
- Lisens: SIL Open Font License 1.1, se `OFL.txt`
