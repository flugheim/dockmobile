## What's new

- Fixed pending-update detection so only real image updates are offered (pinned-digest, newer-version and cooldown rows no longer count).
- Fixed container cards stuck in the busy state after a successful start/stop/restart.
- Release APKs are now signed with a dedicated release key (v1+v2).
- Longer timeout for "Check for updates" (5 min).
- Added a Compose stacks view per environment (status, health, containers, updates).
- Dashboard now loads all environments on open.

## Install

Download `dockmobile.apk` below and install it. This release uses a new signing key, so uninstall any previous version first.
