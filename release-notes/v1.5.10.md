# DockMobile 1.5.10

## Bug Fixes
- **Containers screen now loads on open**: Fixed a regression where the container list would stay on "Loading containers..." indefinitely. The `useFocusEffect` hook that triggers the initial data fetch was accidentally removed during the icon/theme refactor.

## Previous (1.5.9)
- Icons: all buttons, cards, and modals now use Nerd Font glyphs (JetBrainsMono Nerd Font) instead of emoji/text.
- Theme: changed to Tokyo Night color palette (background #1a1b26, accent #7aa2f7, etc.) and JetBrainsMono Nerd Font as UI font.
- New components: `Icon` and `Text` for reusable icons and typography.
