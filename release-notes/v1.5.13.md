# DockMobile 1.5.13

## New Features
- **Release notes for updated containers**: Containers with pending updates now show a "Release notes" button that opens the official GitHub releases page. Supports GHCR and LinuxServer images. Unknown image sources get no button, so the app never shows an incorrect link.

## Previous (1.5.12)
- Fix: stack list layout.

## Previous (1.5.11)
- Fix: stacks screen now loads on open (missing useFocusEffect was preventing initial load).

## Previous (1.5.10)
- Fix: containers screen now loads on open (missing useFocusEffect was preventing initial load).

## Previous (1.5.9)
- Icons: all buttons, cards, and modals now use Nerd Font glyphs (JetBrainsMono Nerd Font) instead of emoji/text.
- Theme: changed to Tokyo Night color palette (background #1a1b26, accent #7aa2f7, etc.) and JetBrainsMono Nerd Font as UI font.
- New components: `Icon` and `Text` for reusable icons and typography.
