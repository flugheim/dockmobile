# DockMobile 1.5.14

## Improvements
- **More compact UI**: buttons, icons, screen headers, cards, filters and lists now use about 20% less space, so more containers, stacks and environments fit on screen at once. Touch targets keep their extra hit area.
- **Tighter update panel**: the pending-update area on container cards is now a stacked panel with the update badge on top and the **Update** / **Release notes** buttons in a row below. It no longer stretches into a large full-width block when the release notes button is shown.

## Previous (1.5.13)
- Release notes: containers with pending updates now show a "Release notes" button that opens the official GitHub releases page (GHCR and LinuxServer images supported).

## Previous (1.5.12)
- Fix: stack list layout.
