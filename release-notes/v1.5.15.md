# DockMobile 1.5.15

## Bug Fixes
- **Icons are no longer clipped**: the right edge of several icons (the info button, the cube on container and stack cards, settings, refresh and others) was cut off. Android measures an icon glyph by its character advance, while the Nerd Font icons are actually wider than that, so part of the drawing was clipped — most visible on high-density screens. Icons now get enough width and stay centered, so every glyph is drawn in full.

## Previous (1.5.14)
- More compact UI: about 20% less space used by buttons, icons, headers, cards, filters and lists.
- Tighter update panel on container cards (badge on top, Update / Release notes buttons in a row below).

## Previous (1.5.13)
- Release notes: containers with pending updates now show a "Release notes" button that opens the official GitHub releases page (GHCR and LinuxServer images supported).
