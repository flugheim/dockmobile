## What's new

- Fixed connection failures in release builds: Android 9+ was blocking cleartext (HTTP) requests to local Dockhand servers. Release builds now allow cleartext traffic, matching debug builds. Fixes #1.
- All API error messages are now localized (English/Norwegian) instead of being Norwegian-only.

## Install

Download `dockmobile.apk` below and install. Updates in place from 1.5.1.
