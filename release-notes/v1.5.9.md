# DockMobile 1.5.9

## Nyheter

**Ikoner**
- Alle knapper, kort og modaler bruker nå Nerd Font-glyfer (JetBrainsMono Nerd Font) i stedet for emoji/tekst.
- Ikoner er vektorbaserte, skalerer perfekt og følger skrifttyppens tykkelse.

**Tema**
- Endret fargepalett til Tokyo Night (bakgrunn #1a1b26, overflate #24283b, accent #7aa2f7, grønn #9ece6a, rød #f7768e, amber #e0af68, osv.).
- JetBrainsMono Nerd Font brukes nå som UI-font i hele appen.

**Tekniske forbedringer**
- Ny `Icon`-komponent med 50+ forhåndsdefinerte glyfer (spill/pause/stopp/omstart, nedlasting, chevron, server, Docker, CPU, minne, nettverk, database, osv.).
- Ny `Text`-komponent som automatisk velger regular/fet basert på `fontWeight`.
- Font lastes ved oppstart via `expo-font` (ingen hvit blink).

## Feilrettelser
- Server info-modal (HostInfoModal) viser ikke lenger tomt vindu når API returnerer tomt innhold.

## Oppgradering
Ingen bruddende endringer. Konfigurasjon og data bevares.
