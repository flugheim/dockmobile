# DockMobile 1.6.0

## New Features
- **Themes**: choose the color theme in **Settings → Appearance**. Three themes ship with this release:
  - **Tokyo Night** (default) — the palette the app has used so far.
  - **Dracula** — dark grey with purple accents.
  - **Nord** — cool blue/teal.
  The choice is stored on the phone and applies immediately, without restarting the app.

## Bug Fixes
- **Correct version number**: every APK built since 1.5.5 reported version 1.5.5, because the Android project kept its own hardcoded version. The build now reads the version from the app, and CI verifies the built APK before cutting a release. This also fixes update tools that kept offering an update that never changed the installed version.
- **Localized screen titles**: the navigation titles ("Environments", "Containers", "Settings", "New stack" …) now follow the selected language instead of being hardcoded.

## Improvements
- The environment picker shows a loading indicator while the environment list is refreshed.
- Removed dead code and silenced all remaining lint warnings.

## Previous (1.5.15)
- Icons are no longer clipped: the right edge of the info, cube, settings, refresh and several other icons was cut off on high-density screens.

## Previous (1.5.14)
- More compact UI (about 20% less space used by buttons, icons, headers, cards, filters and lists).
- Tighter update panel on container cards.
